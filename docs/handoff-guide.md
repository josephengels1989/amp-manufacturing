3. **GitHub Repository** - Where the website code lives (optional access)
4. **Resend Account** - Email service for contact form

---

## How It Works

Your website is a "static site" - meaning it doesn't require a database or server maintenance. It just works. Vercel handles:

- Keeping the site online 24/7
- Automatic SSL certificates (the padlock in browsers)
- Fast loading worldwide
- Security updates

**You don't need to do anything** to keep it running. Just pay the annual domain renewal (~$15/year) when Vercel emails you.
